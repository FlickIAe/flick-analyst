# Flick Analyst ⚡

**Flick Analyst** is an advanced, real-time Web3 token analytics and security auditing platform built for crypto traders and research enthusiasts. It provides instant contract verification, live price charting, honeypot detection, tax analysis, and an integrated multilingual AI chat copilot.

---

## ✨ Key Features

- 🔍 **Instant Contract Search:** Paste any Token Contract Address (CA) across EVM chains or Solana to fetch live market data.
- 🛡️ **Automated Security Audit:** Instant contract security checks powered by GoPlus API (Honeypot detection, buy/sell tax rates, and risk alerts).
- 📊 **Live Market Metrics & Charts:** Embedded real-time price charting via DexScreener, showing pool liquidity, 24h volume, market cap, and native price pairs.
- 🤖 **Context-Aware AI Copilot:** Smart assistant supporting English, Spanish, and Japanese (`EN`, `ES`, `JA`) that dynamically analyzes and responds based on the active token inspected.
- 🎨 **Modern Cyberpunk UI:** Dark-mode interface featuring dynamic Toast notification system for seamlessly displaying status alerts.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS, JavaScript (ES6+ Vanilla)
- **Integrations & APIs:** 
  - [DexScreener API](https://dexscreener.com/) (Market data & chart embedding)
  - [GoPlus Security API](https://gopluslabs.io/) (Smart contract security & honeypot audits)
  - FontAwesome (UI Iconography)
- **Deployment:** Cloudflare Pages
